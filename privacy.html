Privacy Policy

Effective November 12, 2026

Wellspring is a personal tool that runs on its user's own computer and connects only to that user's own YouTube channel. This policy explains what data it accesses, how it is used and stored, and how to remove it.

Data Wellspring accesses

When the user connects their Google account, Wellspring asks for these permissions:

  • Upload videos (youtube.upload): to upload videos the user has approved, set their details and thumbnails, and schedule when they go public.
  • View the YouTube account (youtube.readonly): to read the channel's name, the channel's and its videos' public statistics (views, likes, comments), and YouTube's public chart of popular Education videos.
  • View YouTube Analytics reports (yt-analytics.readonly): to read the channel's watch time and Shorts views, shown to the user as progress toward the YouTube Partner Program requirements.

How the data is used

  • Only to provide the features above to the user who connected the account.
  • Never sold, shared with or transferred to anyone else.
  • Never used for advertising, and never used to train AI models.
  • No other Google account data (such as email, contacts or files) is accessed.

Wellspring's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Where the data is stored

Everything stays on the user's own computer, in a local database. This includes the sign-in token Google issues and the statistics fetched from YouTube. Wellspring has no server of its own, and no data is sent to its developers. Data received from Google is never sent anywhere else.

Keeping and removing data

  • Statistics are refreshed every few hours, replacing the previous ones.
  • Disconnecting YouTube in Wellspring's settings deletes the stored sign-in token from the user's computer.
  • Access can be revoked at any time on the Google security settings page.
  • Deleting Wellspring's data folder removes all remaining data.

Cookies and tracking

Wellspring does not use cookies, analytics trackers or advertising.

YouTube and Google

Wellspring uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Changes

If this policy changes, the new version will be posted on this page with a new date.
